# Car Rental Management System

An internal Car Rental Management System developed
using Odoo 19.

## Project Overview

This project provides an internal platform for
managing company cars and employee reservations.

## Main Features

- Car management (CRUD)
- Car reservation
- Employee reservation history
- Return requests and manager approval
- Car damage management
- Role-based access control

## Technologies

- Python
- Odoo 19
- PostgreSQL
- XML
- Git and GitHub

## Project Status

In development.
